*Pertemuan 4 - CSS3 Layout dan Responsive Web Design*

## Pengembangan 

— Perubahan yang dilakukan: Flexbox dipasang di navigasi dengan `display: flex`, `flex-direction: column`, `justify-content`, `align-items`, dan `gap`. Ditambah juga `margin`, `padding`, serta `list-style: none` supaya daftar navigasinya lebih rapi, dan tampilan link-nya diatur lewat `nav a`.— Commit dan push GitHub: Perubahan sudah disimpan, di-commit, lalu berhasil di-push ke repository GitHub.

## Pengujian 

— Perangkat bergerak: Viewport 375 × 667 px. Navigasi tersusun vertikal dan halaman tetap tampil dengan baik. 
—Desktop: Viewport 1366 × 768 px. Navigasi juga vertikal dan semuanya terlihat normal.—Galat dan perbaikan: Setelah aturan CSS navigasi diperbaiki, tidak ada error lagi.
—Validasi CSS: CSS sudah divalidasi dan bersih dari error. Perbaikan hanya dilakukan di bagian Flexbox dan navigasi agar sesuai ketentuan.# pertemuan-04
